# Generative Adversarial Networks (DCGAN) and Advanced GANs
This repository explores Generative Adversarial Networks (GANs), starting with a baseline DCGAN trained on the CelebA dataset to generate human face images. It then builds toward an advanced GAN implementation with architectural improvements, hyperparameter tuning, and experimental tracking using Weights & Biases.

The goal was to improve generation quality and training stability while experimenting with deeper generator/discriminator layers and varying batch sizes, activation functions, and optimizers. This project serves as a hands-on deep dive into the evolution of generative models from foundational GANs to more robust architectures.
